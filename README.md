# Infra-OS: Form-Centric Construction ERP

A professional, mobile-first Daily Progress Report (DPR) application for construction field engineers and administrators.

**Live Demo:** [https://dprapp.vercel.app/](https://dprapp.vercel.app/)

## Key Features

### 1. Field App (Mobile First)
- **Logic-Driven Forms**: Dynamic questions based on discipline (Pipeline, Civil, E&M).
- **Auto-Summarizer**: Generates standard work descriptions automatically.
- **Offline Ready**: Optimized for field use.

### 2. Admin Dashboard (Desktop)
- **Advanced Analytics**:
    - **Billing & JMR**: Track submitted vs approved bills.
    - **Labour Efficiency**: Monitor gang-wise progress.
    - **Material Inventory**: Live stock tracking with "Pastel" status pills.
- **Visual Maps**: Network map with Pulse animations and Radar coverage.

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS (Premium Pastel Theme)
- **Database**: Supabase (PostgreSQL)
- **Deployment**: Vercel

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/sandeepksp-prog/DPRAPP.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
